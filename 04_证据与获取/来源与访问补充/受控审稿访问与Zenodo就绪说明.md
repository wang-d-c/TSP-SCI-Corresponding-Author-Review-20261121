# 审稿访问与归档准备

公开资料可复算原 600 数字及本轮探索分析，含剥离行尾转换的 Git 清单。路线验环需要 20 图的精确坐标与 596 条授权原字节城市顺序。完整 Timed Windows 重新求解还需要冻结引擎、配置、相应构建版本及资源/停止证明链。

596 条原路线已归档，原 ZIP SHA256 为 `03d302bdcf6db83785299f186dc8f0389314e81358623311f919af29f74a2cf3`。本地回环下载、解压及 596/596 核验的回执继续适用。尚无许可明确的外部受限通道用于发放原始路线和第三方冻结实现，外部账号下载路线、验证全路线与原生端到端复跑仍待作者办理。公开数字 ZIP 的下载结果单列。墙钟协议也无法保证不同机器逐字一致的路线。

Zenodo 就绪材料为公开数字、面板清单、复算程序、版本和可用性说明。建议元数据主标题采用英文主稿标题，类型 `Dataset`，说明固定预算 LKH/TSP 20 图与三臂结果，版本以当前审阅 Git 提交/Release 绑定，日期 2026-11-21。创作者、ORCID、作者对外许可、公开版本和匿名分享范围须由真实作者确认。未保存带真实作者的草稿或注册 DOI。路线路径不随公共附件传输。
