## 1 地图字节和校验

[20 图获取清单](地图获取/map_manifest.csv)提供实际名称、层、点数、定义、源站、命令所需种子及冻结 SHA256。九张 Waterloo 地图直接取得，一张 Heidelberg 地图下载后解压。本轮实测这十张图均可从登记源站取得，字节与冻结 SHA256 一致。下载要保留原字节，手动另存时避免编辑器转换行尾。Waterloo 地图目录分为工程点集和国家地理点集。第三方原始字节的后续再分发仍按权利方条款处理。 [Waterloo VLSI](https://www.math.uwaterloo.ca/tsp/vlsi/index.html) · [Waterloo 国家地图](https://www.math.uwaterloo.ca/tsp/world/countries.html) · [Heidelberg TSPLIB95](https://comopt.ifi.uni-heidelberg.de/software/TSPLIB95/) · [源站直取复验](地图获取/源站直取复验.json)

另有十张从 DIMACS 官方生成器取得。六张 10,000 城图按挑战实例种子生成，四张扩展图使用同一上游代码及冻结种子。项目固定的选图表、调用脚本和四张扩展图的种子配置属于本项目编排。原 C 生成器代码、二进制及其坐标输出不随本包分发。取得作者源站的 `codes.zip` 后，核对 SHA256 `5f041f0b9d68f2397309880919bbfde3d286e1b10b042cc07285f632cee6080a`。源包内文件为 `portgen.c` 与 `portcgen.c`。在 Windows 构建副本中移去未用的 `#include <sys/times.h>`，用 `gcc -O2 -std=gnu99 -ffp-contract=off SOURCE.c -lm -o PROGRAM.exe` 分别生成两程序。其他平台可按源包说明编译。脚本将生成器 stdout 中的 CRLF 转为 LF，再与冻结图 SHA256 比对。同种子仍需通过逐图哈希。 [DIMACS 官方取得页](https://archive.dimacs.rutgers.edu/Challenges/TSP/download.html) · [本机既有生成回执](地图获取/DIMACS_既有生成回执.json) · [10 张图隔离再生成复验](地图获取/DIMACS_隔离再生成复验.json)

在此目录打开终端。Python 3.10 或以上版本的标准库足够执行下列命令；生成图另需上面的已编译程序。文件存在时脚本先核验，保留原文件。

```text
python -B -X utf8 地图获取/panel_inputs.py download --maps inputs
python -B -X utf8 地图获取/panel_inputs.py generate --maps inputs --generators generator-bin --dimacs-archive codes.zip
python -B -X utf8 地图获取/panel_inputs.py verify --maps inputs
```

手动获取时将文件按清单里的 `output_file` 保存到所选输入目录。旧候选、已排除实例及参考值只供核对遴选；论文的当前分析用正式面板和已登记的 EUC_2D。 [历史地图说明](地图历史证据/phase_b_instances/B3_实例来源_规模与暴露核查.md) · [七个地图链接复核](地图历史证据/七个地图链接复核.md) · [冻结距离模型核对](地图历史证据/phase_b_numeric/final_panel_distance_model_binding.csv)

## 2 完整城市顺序和独立校验

[路线索引](路线核验/route_manifest.csv)中的 `tour_file` 是授权交换时建议使用的 `<run_id>.tour`。内容应是既有交付文件的原字节。计长器核对地图及路线的 SHA256、每城恰访一次、闭环及冻结预期长度，整数距离按十进制精确 EUC_2D 四舍五入。将获准的路线放入 `tours` 后运行。路径可指向解压目录之外的合法受控存储，无需复制进投稿压缩包。

```text
python -B -X utf8 路线核验/verify_saved_routes.py --maps inputs --tours tours --report route_check.json
python -B -X utf8 路线核验/verify_saved_routes.py --maps inputs --tours tours --run-id REVIEW20_MAIN_genC12k.seed100003_1421_K_new
```

要提供审稿入口，通讯作者需确认第三方实例及项目生成路线各自可交付的范围，按本刊政策选择受限附件或机构只读临时通道。提交前从独立访问端测试权限、有效期和解包哈希；需要双匿名时请先确认该通道可屏蔽作者身份。可交付的副本仅需 596 条交付环和清单。源码、运行日志、工程暂存和第三方地图需分别审定。目前本包不含完整城市顺序或访问凭据。作者保留本机原件，核对范围见[隔离复验回执](路线核验/596条冻结路线_隔离复验.json)。四个异常槽位没有有效路线，未加入 596 路线索引。
