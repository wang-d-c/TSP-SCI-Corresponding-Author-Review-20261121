# 投稿前作者确认

- [ ] 确认首投期刊、稿件类型和匿名要求。终审以英文主稿、方法统计补充和英文历史附录为一套，上传形式按期刊要求定稿。
- [ ] 全体作者核定署名顺序、真实贡献、单位、通讯作者姓名与邮箱、必要的 ORCID，并同意终稿与提交。
- [ ] 确认基金、利益冲突、原创及未一稿多投等声明。作者按真实使用范围和期刊政策核对 AI 辅助声明。
- [ ] 确认由谁向审稿人提供 596 条受控路线。选定具备适当权限和期限的受限通道，核实外发权利、匿名要求及独立账号访问。冻结原生源码、衍生补丁和二进制分别确认许可与取得方式。
